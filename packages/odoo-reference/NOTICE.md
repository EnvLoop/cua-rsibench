The native guard, action contracts, actor deadline types and original Save helpers are vendored from this repository as source code. Their guard predicates and fixed actor budgets are preserved by a package-local, hash-bound loader. The public factory, verifier, evidence readback, diagnostic integration, CLI and tests are additive successors. No private evaluation dataset, run evidence, account credential, static private authority or historical qualification is redistributed. Licensing and publication approval follow the containing repository's policy; this directory is prepared for review and has not been published by this task.
