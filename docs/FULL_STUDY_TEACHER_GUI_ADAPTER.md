# Train-only teacher GUI adapter

`src/cursibench/full_study_teacher_adapter_v1.py` accepts a frozen `CampaignSession`, one hash-bound researcher proposal, and a cell-owned original-software GUI worker. It emits a private `cua-full-study-rendered-train-batch-v1` manifest and an in-memory Qwen/Qwen3.8-27B batch for `session.dispatch_tinker_sft`. It is a prospective execution adapter, **not** evidence that any real cell, campaign, or hidden result has run.

The proposal must be the mode-0600 `proposal-NNN.private.json` recorded in the campaign journal. Only IDs in `session.views['train']` and its hash-bound train context reach the worker. The adapter rechecks the actual six-cell v0.6.6 ratification before any provider reservation. The teacher configuration must freeze an `agentrouterhub-responses-image-v1` harness, the exact shared v0.6.6 action grammar, Sol 5.6 settings and rate upper bound. Each current-frame screenshot is sent as a private `input_image` data URI with `input_text`; a `teacher_rollout` dollar/call/token reservation is durable before the Responses POST. Missing or ambiguous model/usage fields retain the reservation for reconciliation and cannot become training data.

The worker API is `run_episode(task=..., out_dir=..., sample_teacher=..., dispatch_e2b=...)`. It must show the **original** native or web application, use only current screenshots plus visible controls for each action, recheck the frame immediately before physical GUI dispatch, and write mode-0600 frame PNGs, a canonical action trace, the actor-saved artifact, independent saved-state/no-regression receipt, and fresh reset snapshots/receipt. The returned `episode.private.json` binds every byte and the frozen runtime, verifier, and adapter hashes. A worker that creates an E2B sandbox must use `dispatch_e2b` first; that callback reserves a separate full-lease dollar/hour/concurrency transaction. An externally audited worker implementation is still required to establish that these claimed GUI and verifier operations genuinely happened.

The [Odoo Community train worker](FULL_STUDY_ODOO_TEACHER_EPISODE_WORKER_V066.md) now implements this interface for the self-hosted original application and passes fake-provider contract tests. It has not run a live model episode; its earlier no-model GUI control remains separate evidence.

The adapter renders admitted turns with `scale_action_output_v066.render_for_model`, the pinned Qwen vision renderer, and Tinker supervised datums. Its render receipt records the **right-shifted Tinker datum length**, which is what the dispatcher charges and validates. Earlier `gui-sft-episode-v2` data use an older action output and are never relabeled v0.6.6. The private output directory must be new under ignored `work/`; a failed or uncertain collection is preserved and never automatically replayed.

Synthetic tests cover train-only exclusion, missing ratification, E2B reservation order, provider ambiguity, and tampered frame/trace/saved-state/reset references. A local offline bridge smoke exercised a synthetic frozen dispatcher session, two fake teacher GUI actions, real Qwen image rendering, and fake Tinker dispatch with 1,144 scheduled tokens. This is **interface evidence only**. Remaining live work includes independently audited original-software episodes for all six cells, actual ratified cell freeze, account-specific multimodal provider and E2B billing evidence, and genuine 24-campaign execution.
