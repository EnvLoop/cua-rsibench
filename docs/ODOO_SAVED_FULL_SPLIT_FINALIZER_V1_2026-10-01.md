# Saved-only Odoo full-split visual qualification finalizer

`enterprise_fallback.odoo18.native_reference_split_finalizer_v1` is additive and read-only with respect to existing evidence. It supports exactly 20 selection or 100 official-hidden controls, in the original roster order. It does not create visual approval, run a native environment, call a provider/model, register formal tasks, or rewrite pending result/audit/frame files.

The finalizer accepts only an independently supplied root review with schema `envloop-odoo-v066-full-split-native-source-review-v1` and status `independent_full_split_native_source_frame_review_verified`. Header bindings must match the exact outer/native plans, result, actor/adapter/reference sources and run nonce. Every ordered review row must match the task, family, package, source asset, original native frame, original attempt, independent audit and indexed QA image hashes. All readability/package-match/independence decisions must already be true. Review timestamps must follow both the actual attempt and QA generation.

The production replay reopens the complete 20/100 result, durable batch intent, partition cases, deterministic source assets, source/package/prompt hashes, original frames, QA copies and unscaled native image pixels. It calls the unchanged qualification `_case_row` and `audit_case` for every case and compares each rederived audit with the preserved original. Missing, partial, reordered, old, corrupt or unapproved reviews fail. A failed native batch cannot be finalized. All reopened input hashes are checked again before returning.

`derive(...)` performs the full replay without writing output. `finalize(...)` writes a new owner-only derived receipt next to the plan using exclusive creation. That receipt records original result/audit hashes, the existing root visual review, finalizer source hash and per-case source qualification. The original `source_visual_review_pending=true` files remain unchanged. `formal_task_registration_count=0` and `formal_registration_performed=false` remain explicit.
