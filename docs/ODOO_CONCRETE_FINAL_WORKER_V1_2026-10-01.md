# Concrete Odoo final and shared-base bridges

This implementation closes the Odoo `TrustedFinalWorker.run_once` and current shared-base factory injection paths. It does not admit a final task or produce a benchmark result. The existing real `FinalGate` remains mandatory: all 600 qualified identities, all 24 completed and source-ratified campaigns, selected checkpoint freezes, immutable public witnesses, and the shared budget ledger must validate first.

The final constructor reads source and sealed identity metadata only. An invoked case body, its deterministic source asset and its original private target are opened only after the exact source-bound command, already-dispatched parent reservation and durable private worker intent are verified. The original sealed worker must contain all 100 official identities and all four families with 25 cases each. The manifest key is `official`; the original worker partition is `official_hidden`. Every invoked package is recomputed using the original case JSON plus deterministic native source asset recipe. The actor receives only the current GUI observation and visible instruction.

The native epoch is derived from the explicitly hashed binding's `native-owned-surface-safety-envelope-vN` profile for N >= 8. An optional explicit module must match it. The repo-local module identity, complete public binding, common surface policy, adapter ratification and all-five-slot source/runtime/action/verifier identities are revalidated. There is no latest-epoch lookup, fallback, task/gold/result routing, or historical credit. Source preparation requires an explicit module. The same chosen native adapter, target/nonce/lease guard, Qwen base or actual selected checkpoint sampler, reset and saved-state scorer are used for every slot. A new native epoch changes its source snapshot and requires the new pre-result ratification and qualifications.

Before the 24 campaigns, freeze `study_source_snapshot` as the Odoo cell's `source_snapshot` artifact in the base and every selected manifest. It covers the native worker sources plus this final bridge, shared-base bridge, one-run CLI and original package renderer dependencies. A local supplemental source-binding file alone cannot authorize final execution. The worker rejects a snapshot that omits this closure. The Odoo slot execution metadata must match the native 90-action / 720-second limits, and use the existing deterministic string temperature `"0"`. Source-only test fixtures do not change an actual preregistration.

The original current Qwen GUI loop drives the original application. A raw SDK result and its measured latency are saved before projection into the loop's required `rendered_usage` field. `paid_attempt_id` is the already-dispatched parent final reservation; no invented per-frame paid calls are created. The real Tinker sampler retains its durable request journal and closes its provider session. Uncertain provider or driver completion stops without replay or a fabricated final outcome.

After evaluator-owned GUI reload, the original deterministic verifier performs one actual SELECT readback that is both scored and saved. Its protected physical source files and attachment paths are captured before cold reset. The next post-reset snapshot is fresh. The worker independently reopens the original native artifacts, both full guard images/envelopes, actual dispatch capsules, usage journal, saved state and pre/post reset receipts. It rederives the saved score with the same four original verifiers and protected-source penalties after reset. Ordinary wrong safe actions yield score zero. Actor action/wall exhaustion yields zero under the unchanged final controller policy. Missing saved state, inexact reset, changed source, uncertain IO or absent cleanup cannot become a scored result.

The qualified initial-state projection required by this bridge is SHA256 of the original selection worker's canonical JSON serialization of the actual `baseline_semantic["business_snapshot"]`. The exact database and filestore checkpoint equality is independently checked in the native pre/post reset proofs, and the whole baseline semantic object must equal the restored object. The final admission reset receipts must declare this exact projection; the bridge will not accept an alternative hash as a fallback. Root must align this in the new qualification/admission artifacts before any formal dispatch.

Tests use a real synthetic `FinalGate`, the original actor loop, real cooperative Unix lease and current native guard, original deterministic scorer and production saved-state auditor. Native services and the provider are synthetic. They cover base and selected checkpoint transport, safe wrong results, metadata-only construction, checkpoint/task/unknown-field mismatches, source freeze/epoch conflicts, post-reset failure, missing saved readback and uncertain IO without replay. The shared-base tests instantiate the real current selection-worker factory through the existing legacy runner's keyword API. These tests are source evidence, not authenticated Tinker or native final qualification.

## Root preparation and entry points

After importing the reviewed native epoch and these sources, prepare a fresh source directory explicitly. This operation is source/metadata only and opens no final task:

```bash
PYTHONPATH=.:src:enterprise_fallback/odoo18 "$BENCH_PY" tools/odoo_native_surface_final_v1.py prepare-source --native-worker-module "$QUALIFIED_NATIVE_MODULE" --output-dir "$FRESH_FINAL_SOURCE_DIR"
```

Use `study-source-snapshot.private.json` (its exact raw file hash) as the Odoo source snapshot for all five slots before the pre-campaign freeze. `native-binding.private.json` and `final-source-binding.private.json` are the exact private factory inputs.

The current shared-base entry point is `enterprise_fallback.odoo18.native_surface_shared_base_v1.run_odoo_shared_base(study, usage_reconciler, native_binding_path=..., native_binding_file_sha256=..., train_control_path=..., train_control_sha256=..., worker_dir=..., local_cost_authority_path=..., local_cost_authority_sha256=...)`. It requires the fresh reviewed native TRAIN control, calls the existing budget/coverage runner and injects the current real native selection worker. The caller's frozen base checkpoint and published-rate/local opportunity-cost evidence remain mandatory.

The final worker factory is `enterprise_fallback.odoo18.native_surface_final_worker_v1.final_worker_factory(gate=..., native_binding_path=..., native_binding_file_sha256=..., source_binding_path=..., source_binding_file_sha256=..., worker_dir=..., final_output_root=..., local_cost_authority_path=..., local_cost_authority_sha256=..., enable_live=True)`. Pass that instance as the `odoo-community` worker alongside the other five actual workers in the unchanged `FinalController`. The controller reserves and dispatches; the worker does not select, reserve or retry a task.

For a fresh sealed-worker interpreter, the one-run CLI reconstructs both actual gates and consumes only a command already marked dispatched by the controller. It does not create a reservation or authorize a retry:

```bash
PYTHONPATH=.:src:enterprise_fallback/odoo18 "$BENCH_PY" tools/odoo_native_surface_final_v1.py run-once --repo-root "$BENCH_REPO" --manifest "$PRE_CAMPAIGN_MANIFEST" --prepared-dir "$PREPARED_PRE_CAMPAIGN" --ratification "$SIX_CELL_RATIFICATION" --public-commit "$PRE_CAMPAIGN_COMMIT" --matrix-manifest "$MATRIX_MANIFEST" --prepared-matrix-dir "$PREPARED_MATRIX" --completion-index "$ALL_24_COMPLETIONS" --final-public-commit "$FINAL_FREEZE_COMMIT" --worker-config "$PRIVATE_ODOO_FACTORY_CONFIG" --command "$ALREADY_DISPATCHED_COMMAND" --output-dir "$OWNED_ATTEMPT_DIR" --execute
```

The config has exactly the factory's native module/binding/source binding/worker directory/output root/cost authority fields. Run final in a fresh interpreter with the sealed worker selected before original top-level factory imports; a previously loaded TRAIN/selection worker fails closed. The original native qualification namespaces and consumed attempts are preserved unchanged. Formal results remain blocked until fresh qualification, ratification and all campaigns pass.
