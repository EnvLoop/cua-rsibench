# PowerPoint web selection implementation plan

Goal: accept exactly the frozen 20 WDI v13 selection identities and trained
checkpoint, execute original PowerPoint web GUI rollouts with separately paid
Qwen screenshot samples and actor/reset E2B leases, score downloaded saved
PPTX files independently, then submit a complete private 20-row result.

The source package supplies five country families and eight calculation
workflows, all with three targets in the same slide locations. An
Office-normalized baseline and raw-to-normalized seven-slide/chart/workbook
semantic check are needed for each task. Pre-result positive, partial and
collateral controls must calibrate the saved-state verifier. A per-task
single-file actor lease, exact owner double download and new-copy reset bind
the GUI to an independently scored artifact. A hash chain retains task,
provider and failure trajectories. Live selection authorization stays closed
until the distinct-account Graph permission matrix and manual login pilot are
verified.
