> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Preserve the terminal GitLab evaluator-control failure and provide one explicit, independently audited fresh-clone requalification of the same identity before any further original-roster controls.

**Architecture:** Add a dated recovery module without changing the source-frozen original controller. It copies the first nine passing private attempt trees and their hash-chained journal prefix into a new private branch, while binding the full original failed journal, batch receipts, failed-attempt bytes, and nine-ID audit in a public/private source freeze. An explicit digest-acknowledged command supervises exactly one branch attempt; later-ID continuation remains closed pending a separate controller freeze.
