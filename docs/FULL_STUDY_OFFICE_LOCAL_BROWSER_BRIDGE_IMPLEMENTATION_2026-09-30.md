# Local browser TRAIN bridge implementation

The local bridge now has executable source, a bounded episode loop, a concrete Qwen base sampler, and a connection to the existing v0.6.6 action normalizer. It has been tested with synthetic tab drivers and provider adapters. No native browser model episode, provider request, Graph call, E2B lease, or task registration was executed in this stage.

`tools/office_local_browser_train_bridge_v1.mjs` operates only the evaluator-supplied document tab through documented CUA GUI methods. A native account lease uses one private host/user store across checkouts and artifact directories. The lease token is checked before every frame and action. Exactly one current session for the bound document is required. A mismatched document or unsafe document surface quarantines the episode before another model screenshot is produced.

The model view excludes the Office header and browser navigation. PNG/JPEG dimensions are checked so an ignored crop cannot silently send a full viewport. The actor receives cropped screenshot bytes and task/frame metadata; raw accessibility text, URLs, account data, filenames, and private receipts remain with the evaluator. The dispatcher permits only reviewed regions, focused plain text insertion, a small keyboard allowlist, bounded scrolling, and finish. Scroll distance is explicitly measured in cropped screenshot pixels and converted to native CUA fractional pages by dividing by the crop height; small distances are never rounded up to whole pages. File navigation, account controls, sharing, browser/OS chords, whole-editor fill, URLs, selectors, filesystem operations, and application content APIs are unavailable to the actor.

Actions bind the task, source package, step, frame nonce, pixel hash, frame lifetime, and account lease. Text and key input require a verified document editor focus. Each private frame is saved before sampling. A private GUI intent is flushed before the side effect; an applied or failed terminal record follows it. Intent, application, and failure records contain hashes and fixed error codes rather than typed text. Native stop closes the owned document session before releasing the account lease. A consumed artifact root cannot be reused. The bounded episode loop calls the evaluator's sampler once per frame and stops on finish or an error.

`tools/office_local_browser_train_action_adapter_v1.py` validates complete image bytes and the local frame/profile before invoking the unchanged `scale_action_output_v066.normalize_model_action`. It writes a private normalized action for the CUA dispatcher. The CLI reads only the evaluator's private frame, screenshot, visible instruction, and model-output files. It does not read source CSV or gold, make provider calls, control a browser, or award credit.

`tools/office_local_browser_qwen_base_sampler_v1.py` provides the concrete student sampling path. It validates the complete cropped image and native admission before invoking the existing image-bearing Qwen renderer and durable vision proxy. It uses `Qwen/Qwen3.8-27B` base sampling with temperature zero and seed 23. Checkpoint substitution is refused. The paid boundary requires the root-owned clean runtime and its existing pre-dispatch verifier. The checked Tinker 0.30.0 SDK source exposes `RetryConfig(enable_retry_logic=False)`; the wrapper disables that sampling retry layer and the transport retry layer. Context7's current SDK documentation returned a different retry configuration signature, so the pinned installed interface is the authority for this implementation.

`createOfficeLocalQwenBaseFrameSampler` starts one bounded private Python process for each current frame. It retains a launch intent, stdout, stderr, terminal status, normalized action, and vision-proxy usage receipt. Neither an uncertain launch nor a consumed output directory is automatically replayed. The normalizer still rejects a stale or expired frame after model sampling. Cost USD remains unknown; rendered token counts are not invoices.

Native entry requires a separately accepted manual TRAIN control and an independent source-review receipt bound to the exact bridge, action adapter and sampler source, visible instruction, task binding, account, actor seed hash, crop, and safe-region map. The review must confirm the actor source has no external links. Failed controls, proposals, and fake control receipts are refused. An [explicit one-collection development control](FULL_STUDY_OFFICE_PPT_NATIVE_SAVE_COLLECTION_CONTROL_2026-09-30.md) can be accepted under its distinct status only when its policy hash and all six scorer sources still match. That control preserves raw score zero and provides no generic student scoring qualification. A separate source review and fresh actor binding are still required; no live episode has run.

Validation passed 22 Node tests and 11 bridge/sampler Python tests; four additional native-control refusal tests and related existing Office/proposal checks brought the Python regression run to 44 tests. These include cross-language current-frame normalization to the dispatcher, account serialization across different artifact roots, stale/expired frames, changed lease ownership, duplicate document sessions, unsafe focus/regions/keys, navigation quarantine, enforced crop bounds, rejected fake/proposal controls, receipt/source-review binding, durable pre-GUI intent, rejected checkpoint substitution, image-to-action sampling, uncertain provider no-resubmission, pixel-to-page scroll conversion, and the distinct native-save policy gate. The tests use synthetic tab drivers and provider adapters and are not native execution or isolation evidence.

Run the source checks with:

```bash
OFFICE_TEST_PYTHON=python3.14 node --test tests/test_office_local_browser_train_bridge_v1.mjs
PYTHONPATH=.:src python3.14 -m unittest tests.test_office_local_browser_train_action_adapter_v1 tests.test_office_local_browser_qwen_base_sampler_v1 -q
```

After independent acceptance, the evaluator creates a fresh private artifact root under the durable repository's `work`, writes only the visible instruction, and supplies the bound native document tab, tab inventory callback, binding, accepted control reference, and source review reference. It creates `sampleCurrentFrame` with `createOfficeLocalQwenBaseFrameSampler`, then passes it to `runOfficeLocalTrainEpisode`. The Python interpreter must be the durable root's `work/qwen38-training-runtime/.venv/bin/python`; the module itself verifies that runtime before paid dispatch. These are concrete entry points, not a request for a new Microsoft account or Graph setup.

The automatic subprocess helper inherits the CUA Node process environment. A configured key in the user's shell does not establish that the already-running CUA REPL has `TINKER_API_KEY`. If it is absent, use the same private one-frame CLI from a separately authorized terminal spool: CUA saves the current crop/frame and native admission; the terminal samples and writes a normalized private action; CUA rereads the action and dispatches it against the same still-current frame. Before running the CLI, the terminal may load the existing authorized shell configuration quietly with shell tracing disabled. Keys must never be copied into a CUA argument, model prompt, source file, receipt or tool output. No new key is created or stored by this bridge. The terminal's `PYTHONPATH` must contain only the absolute durable root and its `src`, `PYTHONNOUSERSITE=1`, and the existing root-owned clean-runtime Python must perform the sampling. Force `HF_HUB_OFFLINE=1` and `TRANSFORMERS_OFFLINE=1` for the checked cached renderer. An expired frame is rejected; never resample or replay a consumed spool directory to repair that rejection.

The terminal entry point is `python -m tools.office_local_browser_qwen_base_sampler_v1 --admission ... --frame ... --visible-instruction ... --context ... --out ... --run`, where every ellipsis is an evaluator-private file under the durable root's `work`. Omitting `--run` performs only offline frame/admission checks. Native GUI actions stay in CUA; the terminal process receives no browser session or control capability. Neither environment path has been exercised with a native student in this implementation stage.

The next native development step requires independent review and an accepted control first, then one serialized bounded model episode using the signed-in account and a fresh disposable actor copy. Saved artifact double readback, fresh reset, cleanup, and independent scoring remain evaluator phases outside the actor. Live CUA backend confinement, actual Office save/reset behavior, automated-model qualification, and selection/final scope remain unverified. The original Graph/E2B workers and default selection qualification gates are unchanged.
