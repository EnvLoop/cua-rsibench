# Odoo native loading readiness v8

This additive source epoch retains the common owned-surface policy, native typed principal, 90 actions and 720 seconds, all four workflow families, and unchanged 20 selection / 100 official task rosters. It preserves every v2-v7 source and consumed attempt. It changes when a new observation is taken, not whether a previously observed unsafe action is accepted.

The original v7 TRAIN attempt contains three applied actions followed by a real rejected click. The observed attachment control was disabled and obscured; the same physical point was enabled in the pre-dispatch image. The shared guard correctly returned `target_not_current_and_safe` without a GUI driver call. The old control recorder then reported `gui_dispatch_receipt_not_bound_to_frame`. Its original bytes and rejection remain unchanged and receive no new qualification credit.

Before every observation, v8 passively tracks native document, XHR and fetch requests without inspecting URLs, bodies, task values, requested targets, gold or result state. Websocket and eventsource resources are excluded by resource type. It samples every 250 ms for at most 24 samples, requiring a fresh 500 ms quiet interval, a complete document, an action view, and no visible explicit busy/loading/inert state. Disabled controls are never a readiness condition. The same adapter is installed in the trusted controls, teacher sessions, Qwen base and selected sampler sessions.

Each sample checks the unchanged episode budget, saves its full native image and metadata, and checks the actual held worker lease and owned window/account/surface. Scope or lease loss stops. Continuing loading stops after the bounded wait without a nonce, intent, driver call or replay. The clock spent waiting remains inside the original task budget. An observation may still become unsafe after the barrier: the unchanged pre-dispatch guard then rejects, consumes the turn and nonce, and a model can pay for a fresh turn within its original budget. Trusted controls save the exact rejection reason and stop. Accepted/applied status still requires the real driver result. Uncertain driver completion is never replayed.

The recorder's additive isolated source saves a bound rejected receipt before throwing with the actual guard reason. The outer failure artifact now retains the exception message/code and direct cause. No fabricated applied result or retrospective result file is created.

## Evidence and limits

Source tests exercise the real cooperative lease, production adapter, isolated teacher/student/control registry, recorder and saved-evidence auditor with a synthetic native backend. An optional saved-only test reopens the original v7 loading pair and rederives the original rejection; another feeds those exact raster/target bytes through a synthetic request timing fixture. This is not a new native qualification. Fresh TRAIN plus full selection and official controls, source review and six-cell ratification remain mandatory before formal study results.

A delayed request starting after the quiet interval can still race; the pre-dispatch guard remains authoritative. A continuous document/XHR/fetch stream can produce an infrastructure timeout rather than a task score. Resource-type exclusion does not exempt long-lived XHR. Async changes that remain safe are ordinary model behavior evaluated by independent saved-state scoring. Waiting adds at least roughly half a second per observation and can use the entire six-second bound; no budgets are enlarged. Raw image/metadata capture is sequential, so the independent pre-dispatch envelope remains required.

## Root entry points

Use the new `tools/odoo_v066_native_surface_qualification_v8.py` facade. `prepare` is metadata-only. Root must create a fresh private epoch and may use the already approved legacy roster metadata projection without opening hidden task bodies. A new consumed task attempt is required; never resume the v7 run.

```bash
PYTHONPATH=.:src:enterprise_fallback/odoo18 "$BENCH_PY" tools/odoo_v066_native_surface_qualification_v8.py prepare --legacy-metadata-plan "$ODOO_METADATA" --split train --private-plan "$V8_STAGE/train-plan.private.json" --public-plan "$V8_STAGE/train-plan.public.json" --native-binding "$V8_STAGE/native-binding.private.json"

These retain all 20 / 100 tasks and all four families. No source-only test launches any of these operations.
