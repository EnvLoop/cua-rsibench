# Uniform prospective GitLab task runtime

The actual V5 neutral result verified three fresh cold boots, native telemetry settings, ordered Sidekiq shutdown, exact SQL/full Git readbacks, complete owned teardown and original restoration. This prospective task runtime reuses that proved backend for TRAIN, all 20 selection tasks and all 100 final tasks, with the same base and four checkpoint source closure. Old V6 environments, source, consumed failures and historical outcomes remain unchanged; no credit is transferred.

Every pre/post reset creates a fresh owned COW upper, appends exactly the proved suffix, loads the same environment, reads native poststartup attributes and compares the complete baseline. Ordered shutdown, strict exit checks, immutable seed protection and full Git evidence apply to every generation. The original instance is paused only under the idle exclusive lease and restored after cleanup. Task browser URLs use the existing internal/external port 8018 while the original is paused. The new private namespace copies only fixture metadata, credentials and baseline packages; it copies no task completion or model result.

The shared native safety policy is mandatory for teachers, controls, base and selected checkpoints. Raw observation and predispatch images/envelopes, real kernel lease checks, exclusive nonce/intent records and actual driver receipts are separate from task correctness. Pixel changes alone are not a safety failure. Ownership, URL/project scope, account identity, native context, target geometry, modal and editable focus must remain valid. Rejected actions consume the turn and nonce; a rejected finish cannot end an episode. No action is retargeted and no task answer or current field value enters the safety decision. Native account/schema acceptance still requires the first live TRAIN qualification.

The entire source closure and runtime signatures must be regenerated and ratified before model execution. The old default worker/cohort backend is unavailable through the new factories. TRAIN qualification is a new reviewed intent; its explicit permit does not authorize selection/final inference. A separate full-study permit requires the independent accepted qualification receipt. Provider/model calls remain zero during preparation. Hardware, waits, model/action budgets, samplers, rosters and independent grading stay unchanged.
