# Odoo v6 native safety-envelope adapter

This is a prospective source implementation. It does not activate MAIN, admit
tasks, run a native application/provider, or turn old failures into successes.
The full four-family 20-selection/100-final qualification rosters are retained.

The same adapter class is selected by the teacher, Qwen base/checkpoint worker
and trusted evaluator controls. It preserves the core action grammar, original
task/package/step/nonce/TTL binding, viewport, 90-turn/720-second budget, reset,
saved-state scorer and no-regression checks. It replaces full-raster equality
with the shared source-bound native safety policy.

The real cooperative `worker_lease` registry, held Unix lock, owning PID, lock
bytes and private credential-file hash are checked. The owned browser handle,
worker origin/project and account token bind the lease. Account identity comes
from the rendered user-avatar resource immediately after the existing trusted
browser login; a later UID, credential, lock, origin or window change stops the
adapter. Odoo's [official UserMenu template](https://raw.githubusercontent.com/odoo/odoo/18.0/addons/web/static/src/webclient/user_menu/user_menu.xml)
identifies the visible avatar component. No account API, hidden task answer,
database lookup or expected business value is used by the action-safety gate.

Before each decision the adapter saves the full observation/current image and
native metadata. It then saves a fresh real lease-check receipt, consumes the
nonce durably and writes the action intent before any native driver call.
Driver start and actual return records are separate. Targeted keyboard input
rechecks current ownership, lease and editable focus after the target click.
Unknown or partial driver failures retain their true status and quarantine the
adapter; they never become `applied/ok` or an automatic replay.

Safe raster or displayed-value changes do not invalidate an action. A safe
wrong-object operation is permitted and the independent task verifier must
score it. Recoverable context/modal/focus/target/expiry rejection applies no GUI
action, consumes the turn and old nonce, and exposes truthful rejection
feedback on the next full observation. A logical `finish` is recorded as
`finished`, with no native driver-success claim. Controls require actual applied
operations and stop on rejection. Model loops may use a new bounded turn; paid
requests and old actions are never replayed.

Saved audits reopen the unmodified images, derive native target/focus/context
fields again from retained native metadata, recheck owned origin/window/account
against the held-lease proof, rederive the shared decision at its original
decision-time clock, and reopen nonce/intent/driver-start/return evidence. A
captured boolean or a screenshot hash alone is insufficient.

Validation: **107 tests passed in 1.815 seconds**. They include the actual saved
v3 three-pixel and v4 eleven-pixel raster pairs, unchanged full-image retention,
scope/account/lease/viewport/modal/focus/target negatives, expired/reused nonce,
unknown native IO, post-click focus loss, logical finish, forged evidence and
safe wrong-object rejection by an independent fixture goal. The old pixel
pairs are actual retained bytes; their current safety metadata is a unit
fixture, not retrospective native qualification. Six additional production-
helper tests use the real Unix lease with synthetic private files and a fake
UI. No browser, provider, hidden task body or real worker was executed.

The shared external teacher callback can still reject expiry before returning
an action. Until its equivalent additive feedback amendment is integrated, that
failure remains a stopped original call, not a claimed recovered action. The
preserved native mechanics also recheck core TTL before IO; a clock crossing
at that boundary fails truthfully before a native success claim.

Use `tools.odoo_v066_native_surface_qualification_v6 prepare` to bind fresh
TRAIN, selection and official-hidden metadata plans. Run one new original-
Odoo TRAIN control, independently inspect its saved source frame and finalize
its new proof. Then run the unchanged complete 20/100 controls in
`private/v066_native_surface_controls_v6/native-v6-<fresh nonce>`. Old v2–v5
proofs cannot admit this namespace. All source-only model paths still require
fresh six-cell policy/plugin ratification, common checkpoint/runtime bindings,
authentic paid accounting and independent final scoring before formal results.
