# Odoo actual V22 final dispatch

This additive worker uses the current V13 native actor, independent SQL and
physical-file scorer, exact reset, native guard and typed 720-second actor
clock. It leaves the 57-file V13 control binding unchanged. Its separate final
source snapshot must be closed before any research campaign. Existing control
proofs qualify the native source only; they do not admit formal model results.

The constructor reads metadata only. `run_once` first checks the real witnessed
V22 FinalGate, all 600 qualified tasks and all 24 completed research chains,
exact 100-task identities, owner, checkpoint hash/path, common runtime/source
snapshot, sampling, private output and the already-dispatched parent paid
reservation. Only then does it open that command's private final task body.
The same worker handles shared base and all four selected checkpoint slots.

Each task owns a fresh sampler and native environment. The actor gets 90 GUI
turns and an absolute 720-second deadline; setup, saved-state readback, exact
reset and acknowledged provider close are measured separately within the
owned 1200-second lifecycle. A typed terminal deadline may retain independently
scored performance only with the reopened V13 budget-performance proof.
Ordinary provider faults and uncertain native I/O do not become scored budget
stops. No consumed request is automatically replayed.

The parent whole-task paid ID is retained. Each frame records the actual Tinker
sampling-journal request ID, durable intent and actual completed result, or a
null result for the checked terminal deadline. Usage and invoice amounts stay
null when the provider has not supplied authentic billing; a nominal quote is
not an observed charge.
