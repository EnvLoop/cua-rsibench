# Original Office native source v3

This additive source preserves the v2 runtime and every retained native attempt. Root owns native execution and qualification. Source tests and saved-profile projection do not qualify a native lifecycle or score a model.

Downloads use `download_surface: folder_toolbar`. The evaluator first observes the exact native saved-status label on `#SaveStatusButton` in the document iframe. It then navigates to the dedicated folder, reopens full inventory evidence, selects the exact owned filename row, and captures two genuine toolbar download events. The event filename must equal the document filename; folder ZIP downloads are refused. No editor export recipe is substituted.

Full inventory uses the actual parent folder-card count. The private profile binds the exact parent URL/hash, exact child card selector and name, and its visible `SPAN.ms-FolderCover-metadata` inside `DIV[aria-label="Yellow folder"]`. The source retains parent evidence, returns to the exact child, rereads rows and compares the badge count with those rows. Empty state also requires the actual empty-folder UI. Row length or selected-item count alone never proves inventory. Folder navigation deliberately restores fresh semantic DOM state after an earlier account-popup inspection.

The host resolves only requested refs, geometry and current context/modal state. Unrelated target or focus changes do not reject a pointer action. Targetless keyboard actions bind the actual focus; coordinates retain the same physical targets and are never retargeted. The shared native policy and durable operation/nonce gates remain unchanged.

App navigation/save keyboard focus is separate from editable typing. Native thumbnails/options, canvas and editor panes can admit keyboard actions when current, visible and unobscured. Typing requires actual editable focus; fill/select-all retain the stronger selection profile. Account/header/export/navigation links stay unsafe.

Document identity still binds the actual document URL, filename and document-owner CID. `document_owner_sha256` is explicitly separate from `account_principal_sha256`. The latter derives from the existing account's observed native signed-in UI email. Passive folder/editor controls are reread against initial private control snapshots and the original account-popup witness. This reports display-label continuity from a native email witness, not exact live email observation. Account popups are never opened for actor captures, and no account label/email enters actor metadata or public artifacts.

## Root initializer

Import `office_owned_folder_cua_pump_v3.mjs` and call its `officeV3SourceHashes()` before freezing the private binding/admission. Both must include that exact map as `supplemental_source_sha256s`. The pump preserves the existing v2 operation wire format while using v3 lifecycle, host, extractor and profile code. The private profile schema is `office-owned-folder-native-ui-profile-v3`.

The private inventory profile is:

```javascript
folder_inventory_proof: {
  mode: 'parent_card_count', parent_url, parent_url_sha256,
  card_selector, name_selector: '[data-automationid="name"]',
  count_selector: '[aria-label="Yellow folder"] .ms-FolderCover-metadata'
}
```

Use the exact observed card selector and heading from the dedicated child. Do not include protected staging rows. The private account profile for each surface is:

```javascript
{
  schema: 'office-signed-in-ui-principal-profile-v3',
  source_reviewed: true, mode: 'passive_label_continuity', open_steps: [],
  identity_control, identity_frame_selector,
  initial_popup_ref: {path: private_native_popup_file, sha256},
  initial_control_ref: {path: private_passive_control_file, sha256}
}
```

Folder uses its actual reviewed account button role/name. Editor uses `identity_frame_selector: 'iframe#WacFrame_PowerPoint_0'` and `identity_control: {selector: '#O365_MainLink_Me'}`. `signedInPrincipalFromPopup()` derives the principal hash from the native Sign out control's actual email witness. Do not use the CID hash as signed-in identity. The public source contains no account identity or private URL.

The root factory remains `createOfficeCuaOperationPump({folderTab,browser,binding,profile,spoolRoot,evidenceRoot,sourceAdmission,listDocumentTabIds})`. No UI call occurs during construction. A one-use request claim is durable before native operations. Missing or changed source, account, folder, saved-status or item evidence fails closed and is never replayed.
