This additive source path uses the existing Microsoft account and a fresh empty disposable OneDrive task folder. It preserves the older diagnostic bridges, human-save proposals and all historical raw failures. It performs no Graph operation and creates no new account. These sources are not an Office20/100 qualification receipt.

Its actor projection contains the visible instruction and opaque identity hashes; answers, source snapshots and verifier state remain evaluator-only. The task, baseline and every source sidecar are reopened against their frozen hashes. PPT scoring calls the existing strict saved-OOXML verifier. The read-only native extractor uses actual DOM rectangles, computed visibility, obstruction and current focus. It does not mutate DOM attributes or encode task answers. Administrative navigation/account/export controls remain unsafe. Native identity, editor mode and private-header exclusion are checked. The shared policy gates each action, consumes every nonce and retains an intent before the driver. Accepted target resolution is lazy; a removed or changed native target is rejected without retargeting. Pixel changes do not decide acceptance.

The Python native-operation spool and CUA pump retain a durable one-use claim before UI calls. Unknown operations preserve their handles and shared account lease. They never restart or replay a consumed operation. The sampler uses a separate terminal process, inheriting the terminal's configured provider environment. No credential is passed into CUA, screenshots or public artifacts.
