# PowerPoint-web chart-caption training control

**Development result, 2026-09-27.** One final-shaped task was built from a *training* WDI source family. The operator used the signed-in PowerPoint web editor to correct four separate locations in a seven-slide analyst brief: summary, native-chart caption, calculation-table cell, and interpretation. Each editor action was selected against visible text; the saved file was downloaded and scored by the independent OOXML verifier. The [field-limited receipt](ppt-wdi-powerpoint-web-chart-caption-triad-2026-09-27.json) commits to the private task, cloud item identities, source and role artifacts, oracle, scorer, and seven-page visual check without publishing an answer or account URL.

The source was first opened, neutrally edited and undone so that the evaluator could freeze an Office-saved baseline with all draft text still intact. The baseline's visible slide objects, WDI table, native chart, and embedded workbook were checked against the original training-source deck. Three distinct cloud items were then uploaded from **byte-identical copies** of that normalized baseline. After each edit run, the operator reloaded the editor and refreshed OneDrive before the readback download; an earlier immediate download returned a stale pre-save copy and was excluded from scoring.

The downloaded positive corrected **4/4 targets and scored 1** with preservation accepted. The downloaded near miss corrected **3/4 targets and scored 0**, while preserving every unflagged package part. A newly opened fresh copy downloaded **byte-identically** to the frozen baseline and scored 0. Two separately labeled direct-file attacks against the otherwise correct positive—altering native chart data and changing unrelated text—both scored 0. The positive PDF was rendered and all seven pages were visually reviewed for layout and correct target text.

The Office-web verifier permits only observed text-run segmentation, default style flags, ASCII target-font fallback, narrow table metadata, and chart opaque IDs at designated target objects. It still compares all non-target content, chart values, workbook bytes, source observations, and visible target text. This is one evaluator-scripted **training-source** control: **no hidden final identity, Qwen attempt, or researcher campaign is admitted**. The 100 offline PowerPoint candidates still require per-ID cloud positive/near-miss/reset controls before a final-set freeze.
