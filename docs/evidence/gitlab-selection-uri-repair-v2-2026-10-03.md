The retained task context and exact source establish this defect. No browser URL or screenshot was captured between navigation and that assertion, so the requested single-slash URL is a code-derived value rather than an observed browser URL.

It rejects credentials, foreign origins and projects, extra slashes, noncanonical project paths and unsupported relative paths. URI refusal diagnostics are private and omit credentials, query and fragment. Original recipes, tasks, native source, budgets, verifier and reset remain unchanged.
