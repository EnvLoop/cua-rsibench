A model-format failure is scored zero only after saved OOXML readback and independent fair target/no-regression verification. Provider uncertainty, physical drift, parser expiry, lost save, or cleanup ambiguity invalidates the attempt without imputing a model zero.

The actor guest is terminated before a **second, separately reserved E2B lease** creates a fresh reset guest for the same source package. The runner compares scoped guest content, neutral LibreOffice profile, original source semantics, and saved reset bytes, then terminates that guest. Every task retains a private action/frame ledger, actor-saved OOXML and neutral baseline, independent verifier receipt, distinct-sandbox reset proof, and cleanup receipt.
