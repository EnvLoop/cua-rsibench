# Native LibreOffice v0.6.6 train teacher worker — offline evidence

The [aggregate JSON receipt](native-wdi-v066-teacher-worker-offline-2026-09-28.json) contains only counts and source hashes. Per-task packages, instructions, oracles, frames, and saved files remain private.

The [Desktop train worker](../../native_desktop_factory/teacher_episode_worker_v066.py) now implements the shared `run_episode(task, out_dir, sample_teacher, dispatch_e2b)` interface for the original LibreOffice Calc, Impress, and Writer cell. It accepts a task only when its ID, package SHA-256, and visible instruction match one of the frozen **20 WDI training packages**. The source, template, and instance groups are checked for disjointness from the **20 selection** and **100 final candidates**. Only the selected training package is opened; no selection or final instruction or oracle is sent to the teacher.

The worker requires a scoped guest-content digest and exact E2B Desktop resource shape before staging. In trusted setup it opens the source document, saves a neutral native baseline, independently compares the WDI source semantics and non-target content, then captures a canonical LibreOffice profile. The actor loop sends the teacher actual 1280×800 GUI screenshots under the common v0.6.6 action parser. Each accepted action has a mode-0600 raw observation frame, a separate raw pre-dispatch frame, a current-frame recheck, a bounded action trace, and GUI-only dispatch. A `finish` action triggers evaluator-side readback of the actor-saved OOXML and the pre-result fair target/no-regression scorer. A **second, separately reserved E2B lease** opens the original training source in a distinct fresh guest, repeats guest/profile attestation, and checks the reset semantics. Both sandboxes must terminate. The worker caps actions at 90, each lease at 600 seconds, whole-episode time at 1,350 seconds, private episode evidence at 96 MiB, and host free space at an 8-GiB floor. Its two E2B leases each reserve $0.166666667 at the conservative $1/hour full-lease rate; the shared campaign ledger may impose a higher frozen rate.

The [shared teacher adapter](../../src/cursibench/full_study_teacher_adapter_v1.py) gained a backward-compatible `phase='actor'|'reset'` argument. The original single lease ID and request shape remain for one-lease cells. Only a worker declaring `requires_fresh_e2b_reset=True` may request a second lease, only after the teacher's final `finish` action; the second lease has a distinct paid attempt ID and its own full reserve. A third lease and sandbox-ID reuse are rejected. Both lease IDs must appear in the private episode receipt before the adapter can admit it.

The offline tests use the **actual private WDI training packages** and preserved real saved positives for one Calc, one Impress, and one Writer case. A fake E2B guest supplies only the provider/session boundary; the worker still runs the independent OOXML scorer and the shared episode readback validator. Three synthetic episodes passed, each with two distinct fake sandboxes and raw frame readback. A separate integration test drove the shared collection adapter through one fake Desktop episode and confirmed its two E2B reservation intents surround the teacher calls, with a train-only dataset manifest. A local fake SDK additionally exercised the **real guest preparation code** for Calc, Impress, and Writer, including provider shape, scoped content, fresh profile, native neutral save, and two-guest profile equivalence. Tests also reject selection/final tasks before any provider call, changed inventory or guest reference hashes, unsolved saved OOXML, profile drift, reset sandbox reuse, tampered raw pre-dispatch frames, an unratified real backend, premature reset, and a third lease. The broader shared/desktop/Odoo/campaign/matrix regression suite passed **71 tests**. These are fake-provider and offline checks: **0 live teacher or E2B calls**, **0 real train episodes**, **0 selection/final model calls**, and **0 official final admissions**.

The real Desktop worker remains disabled by default. Before any paid training episode, it requires a private six-cell v0.6.6 ratification whose adapter SHA-256 matches the installed Desktop adapter, frozen runtime/verifier bindings equal to the worker's measured source/scorer hashes, and exact candidate-inventory and guest-reference hashes. A live 20-task train calibration, including task-specific neutral saves and profile equivalence in two real guests, has **not** been run. A neutral Impress save is required because the raw generated PPTX changed untouched geometry on first LibreOffice save in earlier development; the worker refuses a missing normalization, checks that all text boxes remain within the slide canvas, and scores edits against the checked neutral baseline. The other four train Impress neutral results still need real visual review before publication. The existing 100 historical Desktop GUI controls, the exhausted $40 development lane, and official result count remain unchanged.
