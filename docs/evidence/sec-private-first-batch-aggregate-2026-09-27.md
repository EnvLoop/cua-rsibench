# First evaluator-held Excel source and workflow batch

The [aggregate receipt](sec-private-first-batch-aggregate-2026-09-27.json) records **four new issuer families** whose **44 selected two-period USD facts** were checked against the tables in their non-proxy original SEC 10-K HTML filings. Exact issuer, accession, concept, fiscal-period, value, source-line, and independent-check records remain evaluator-held. The wider proxy-delivered companyfacts payloads have **not** been authenticated. The other 36 new issuer candidates have not yet received task-specific numeric review. These statements describe a bounded source batch and do not imply SEC endorsement.

Two new semantic workflow families are held privately outside the ten public development graphs. Four ten-sheet actor/reference workbook pairs were built from the checked facts. An independent saved-OOXML oracle recomputed **232** target formulas, used two source/scenario perturbation profiles per case, required unrelated cells and workbook structure to remain unchanged, and passed all four reference solutions while rejecting all four unrepaired seeds. All **36** injected formula faults were individually detected. A hardcoded filing value and a collateral source edit were rejected for both workflow families. Every sheet of a representative workbook from each family was rendered and visually checked. The synthetic scenario drivers are separated from SEC facts in the workbook and oracle.

An evaluator-only ledger reserves **20 train / 20 selection / 100 final slots**, across 28 issuer-family slots and ten proposed final-template slots, with cross-split isolation. These are **reservations**, not task records: four offline calibration candidates occupy train reservations and **136 slots remain unfilled**. The [structural private-split screen](sec-private-split-readiness-2026-09-25.md) therefore still admits **zero** private tasks. At the time of this offline snapshot, no case had a dedicated-account Microsoft Excel for the web saved/downloaded readback, GUI positive/negative control, or fresh-copy reset, so the official Excel-web final count was **0/100**. The Mac was later unlocked for original-software calibration.

The paragraph above records the first-batch **offline snapshot**. A later [Excel-web GUI development-control addendum](sec-private-excel-web-development-triad-2026-09-27.md) documents one positive/near-miss/reset triad with downloaded-artifact readback; it does not change the official final count.
