# Two tax-position TRAIN analogues: offline controls

The [field-limited receipt](sec-tax-two-train-offline-control-2026-09-29.json) binds two source-disjoint TRAIN-only packages to the [source freeze](sec-tax-train-two-source-freeze-2026-09-29.json). Each package uses two annual periods from an original SEC filing. Both signed gross uncertain-tax-position rollforwards reconcile within each package. The separately accrued interest and penalties balances stay outside the gross bridge. One source reports net interest expense; the other reports combined interest and penalties expense, including a signed benefit in its current year. Categories that are not separately reported remain marked `n.r.` in the workbook; a zero is used only as an explicit bridge convention, not called a filed amount.

The authoring code generates one faulty seed and one repaired seven-sheet reference per package, with 12 unmarked formula repairs in each seed. A separate saved-OOXML oracle recomputes expected values from the reviewed source packages. Both references pass, both seeds fail, all 24 one-repair-short copies fail, and all 24 individually hardcoded target formulas fail. Ten semantic negatives, two collateral filed-fact edits, two style changes, two stale cache changes and two deleted cache controls fail. Each repaired workbook passes 11 source/scenario counterfactual replays, including a joint accrued-balance and accrual-rate change. Fresh reset copies match their original seed bytes. The seven rendered tabs in both repaired workbooks were visually reviewed.

This is offline TRAIN source-transfer evidence. No Microsoft Excel for the web control, model call, official final-task admission, or model improvement is claimed. The evaluator keeps the source review, original raw filings, workbooks, and full audit privately; the public receipt contains only counts and SHA-256 commitments. [SEC EDGAR](https://www.sec.gov/search-filings/edgar-application-programming-interfaces) is the source method, and the SEC does not endorse this benchmark.
