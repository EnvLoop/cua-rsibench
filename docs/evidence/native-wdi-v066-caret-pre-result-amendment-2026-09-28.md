# Pre-result Desktop v0.6.6 caret-frame amendment — 2026-09-28

**Status:** Proposed before any new paid evaluator control or official final model outcome. The historical v0.6.6 source and all 22 original E2B intents remain intact. This document does not admit a task or report a model score.

The original evaluator-only Desktop run has seven complete GUI trios, one partial positive attempt stopped on `PhysicalFrameDrift`, and 92 final tasks untouched. The failed action was the 34th of 53 expected actions. Its first observation-to-predispatch difference was a real 11,896-pixel application transition; four subsequent attempts differed by the same 1-by-42-pixel vertical insertion-caret toggle. Across 15 actor attempts, the controls retained 257 drift pairs, including 158 small vertical-line pairs. These are control traces, not final model outcomes. The observed one failure in 15 actor attempts is too small to estimate a stable failure probability, but the repeated transient pattern makes a same-source one-time retry an inadequate basis for a 100-task publication claim.

The amended **Desktop-only** adapter retains the shared v0.6.6 action/output protocol. On a changed application screenshot, it considers only one contiguous one-pixel vertical column, 10–45 pixels high, with at most three color pairs and one predominant pair. It samples at most five more screenshots over at most 1.25 seconds. The action is accepted only when the *entire application crop returns exactly* to the original observed pixels; any persistent line, third state, wider change, or invalid screenshot remains `PhysicalFrameDrift`. The accepted action still has matching raw observation and predispatch application frames. The historical actor script, task packages, independent saved-OOXML scorer, and old adapter bytes are not changed.

Offline replay used five **train-only** native GUI traces, reopening all 28 raw drift pairs against receipt hashes. Nine pairs had the narrow caret shape; 19 material or other pairs were rejected. Synthetic tests accept a two-state return and reject a persistent one-pixel edit, a third application state, and a 10-by-10 content change. Shape replay alone does not claim a live two-state return or successful full task. No E2B or model call was made for this amendment.

The old private evidence was reopened read-only: 22 distinct intents and sandbox receipts, seven complete trios, one failed partial task, the stopped journal, 1,435 raw ledger rows (208,550,165 bytes), and 1,480 files in the attempts tree.
