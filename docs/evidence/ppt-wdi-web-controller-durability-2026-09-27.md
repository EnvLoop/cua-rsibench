# PowerPoint web controller durability check — 2026-09-27

The [aggregate machine-readable receipt](ppt-wdi-web-controller-durability-2026-09-27.json) binds a **training-source** four-target deck, the evaluator-side [GUI controller](../../tools/ppt_wdi_web_gui_controller_v1.js), an Office-normalized saved baseline, and four independently downloaded PPTX outcomes. The controller uses visible OneDrive/PowerPoint interactions and retains cloud locations and raw artifacts only in evaluator-private storage.

The first download after a positive edit and the first download after a three-edit near miss were both byte-identical to the uploaded baseline, even though the editor displayed the corrected text. A separate fresh PowerPoint session showed the saved edits, and a later OneDrive download contained them. Therefore editor text or a “Saved to OneDrive” indicator alone is **insufficient admission evidence**. The controller now performs a separate fresh-session readback and second download; the independent OOXML verifier, not the browser status, decides whether the saved outcome is valid.

The durable training-source downloads scored **positive 1/1** (all four targets correct, preservation passed), **near miss 0/1** (three targets changed, preservation passed), and **fresh reset 0/1** (no target changed, preservation passed). A separate GUI edit to an untouched chart-unit shape scored **0/1** with preservation failure. The source and Office-normalized baseline retain the same seven slides, visible text and table, embedded chart workbook, and chart-cache values. This is a controller calibration, with no model calls and **0/100 PowerPoint final admissions**.

For every final candidate, the evaluator still needs a separate normalized baseline, four isolated role copies, per-role saved/downloaded artifact scoring, same-file restoration, source-family isolation and signed receipts. Any stale download must be retained and excluded, never counted as a success or a model failure. The common six-cell protocol and budget freeze remains pending.
