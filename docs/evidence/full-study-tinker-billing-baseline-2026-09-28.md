# Read-only Tinker organization usage baseline

The [field-limited receipt](full-study-tinker-billing-baseline-2026-09-28.json) records one authenticated, read-only 24-hour billing-usage query before any full-study campaign. It returned 48 hourly organization event rows and 13 session entries. These are **organization-wide historical events, not 48 EnvLoop study calls or 13 benchmark sessions**. Raw provider data, including user and session attribution, is retained only in a mode-0700 ignored `work/` directory. The public receipt contains event-type counts and hashes, with no identifiers or task contents.

The installed Tinker SDK 0.30.0 response supplied token/storage quantities but no estimated-cost fields, completeness watermark, invoice amount, or available credit balance in this query. Therefore the receipt cannot settle campaign costs or prove funding for the planned 24 budgets. Tinker's [billing-usage API documentation](https://tinker-docs.thinkingmachines.ai/tinker/api-reference/restclient/#get_billing_usage) describes hourly usage and distinguishes gross estimates from invoice amounts; its current documentation may expose fields newer than this pinned SDK. Future study-specific reconciliation must filter campaign-tagged sessions, retain every provider usage event, and obtain a billing/invoice basis separately from published rates and local token counts.

The [collector](../../tools/preflight_full_study_tinker_billing_v1.py) refuses non-UTC, unaligned, future, or more-than-14-day windows and validates every event before publishing safe aggregates. It does not call training or sampling APIs. Official task admissions and completed campaigns remain zero.
