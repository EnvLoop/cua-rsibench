# SEC Excel transfer: 22 additional original-filing source bundles

**Status: raw source capture and independent identity replay complete; semantic review and case admission pending.** The [capture receipt](sec-train-22-raw-source-capture-2026-09-29.json) and [read-only audit](sec-train-22-raw-source-audit-2026-09-29.json) cover 22 new issuer-distinct original 10-K accessions, privately allocated as two candidate source families for each of the 11 causal graphs not covered by the prior four-case TRAIN pilot. The frozen 140-slot original train/selection/final issuer and accession registry and the previous four TRAIN sources were checked before downloading. No issuer or accession overlaps either set. The 13 signed graph cards were used only for source allocation and signature checks; a graph assignment does not establish that the filing contains all required exact facts.

Each bundle preserves the [SEC submissions JSON](https://www.sec.gov/search-filings/edgar-application-programming-interfaces), original filing index, the indexed primary 10-K HTML, and the exact-accession CompanyFacts JSON. Three split filings additionally preserve an indexed source-bearing HTML exhibit incorporated into the same accession. Original response URLs, retrieval time, HTTP 200 and verified TLS metadata, file lengths, and SHA-256 digests are evaluator-private. Capture used a declared contact User-Agent and was paced at approximately one SEC request per second within each process, below the [SEC fair-access guidance](https://www.sec.gov/files/privacy.htm). The final source pool contains **91 original response files / 218,186,933 bytes**. The public receipts expose counts and salted commitments, without issuer identities, accessions, workbook answers, or account details. The raw pool is under an ignored evaluator-held directory with `0700` directories and `0600` files.

An independent read-only auditor reopened all 22 manifests and all 91 saved files. It rehashed every file, checked HTTPS source URLs and response metadata, matched each original 10-K accession, form, date, report period, and primary document to the SEC submissions and index, confirmed the three supporting documents appear in the corresponding index, and found same-accession facts in CompanyFacts. This is **source identity and provenance**, not exact-field semantic verification. In particular, a section heading or a CompanyFacts accession match does not prove the correct plan, unit, scope, table row, sign, or two-period arithmetic for any graph.

The four earlier source-bound TRAIN analogues remain the only cases with independent saved-OOXML positive, near-miss, hardcode, collateral, and counterfactual controls. The 22 new bundles have **zero** completed per-field semantic reviews, **zero** authored seed/reference workbook pairs, and **zero** Excel-for-the-web save/download/reset controls. Thus the 26-case screen has 26 distinct candidate filing sources but only four offline workbook-controlled cases and **zero** admitted Excel-web training cases. There are no official final admissions or model-effect claims from this source capture.

The next gate is a private, independent exact-fact review for each of the 22 source families against its signed causal card, including two-period scope and graph-specific reconciliation. A family that fails must be replaced with a new issuer before a workbook is authored. Passing families then need separate scenario labels, source-disjoint authored templates, saved-OOXML positive and negative controls with source/scenario counterfactuals, and original Excel-for-the-web saved readback and fresh-copy reset. The [SEC guidance on public EDGAR reuse](https://www.sec.gov/about/webmaster-frequently-asked-questions) informs access; the intended public benchmark tier remains derived filing facts and authored scenarios, without redistribution of full filing HTML or any suggestion of SEC endorsement.
