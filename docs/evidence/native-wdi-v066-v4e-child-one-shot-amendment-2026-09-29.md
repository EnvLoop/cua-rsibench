# Desktop v0.6.6 v4e child one-shot amendment

The first v4e source-only freeze was prepared before this review found a direct-child replay gap. The parent already refused a second invocation when durable child stdout or stderr existed. A child invoked directly after an uncertain failure with no saved `receipt.json` could still pass the precreate gate. No E2B sandbox was created under that freeze, and it remains without dispatch authority.

The additive v5 source freeze binds an exclusive, fsynced `child-started.json` marker to the exact task, polarity, intent, freeze, and reviewed permit before the original evaluator can create a sandbox. A second child invocation against the same intent raises `FileExistsError` before entering the evaluator. The independent saved-state auditor now requires and checks that marker alongside the durable stdout/stderr, terminal output, provider receipt, saved OOXML, negative control, and cold reset. The existing no-replay, sequential roster, and full-lease accounting rules remain in force.

Offline checks on the actual private candidate inventory confirm 100 distinct final candidates, a shuffled raw order distinct from the frozen sorted roster, the historical stopped intent at sorted index 11, and the first untouched task at sorted index 12. The retained eight complete trios and four partial logical IDs were reopened; the fifth root remains unused. The original four-root bridge validates under the v4e fifth-root patch. Eleven targeted tests pass, including an adversarial direct second-child call without a receipt and a marker-tampering rejection. These are source and readback checks only: official final admissions, model attempts, and new v4e E2B creates remain zero.

The v5 private freeze is bound to this isolated checkout for review. It is not portable to the main checkout because source paths and public-freeze hashes are absolute. Main must prepare a new source-only freeze after cherry-picking the child, auditor, and test changes, then run the independent readback audit and create a separate one-batch review and permit for the exact next sorted task. If a paid attempt has uncertain cleanup or an incomplete trio, the batch stops and the intent is not replayed; continuation requires a new explicit source and reconciliation decision.
