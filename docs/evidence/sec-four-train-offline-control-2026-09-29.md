# Four SEC Excel transfer cases: offline TRAIN controls

**Status: four source-bound training analogues passed offline saved-file controls; no Excel-for-the-web task was admitted.** The [aggregate receipt](sec-four-train-offline-control-2026-09-29.json) binds four original SEC 10-K/index/CompanyFacts bundles and two independently reviewed causal skill-card profiles. The four issuers and accessions are distinct from one another and from all 140 original benchmark anchors. Original fact values, fiscal periods, units, tags, note rows, and raw-file hashes remain in evaluator-held files. Scenario rates and cash-flow changes are separately labeled authored assumptions.

Each case has a six-sheet editable seed and an offline authored positive reference. The actor-facing seed contains 12 unmarked formula defects spanning source selection, signed flows or debt components, historical reconciliation, a synthetic scenario, and an output. An independent OOXML scorer reads saved workbooks, recomputes expected values from the reviewed private source packages without importing the builder, checks non-target cells and workbook structure, evaluates formulas and visible cached values, and reruns source and scenario counterfactuals. Every target has a changed-value dependency witness.

All four positives passed and all four unrepaired seeds failed. The verifier rejected **48/48** one-target-short variants, **48/48** individually hardcoded targets, **12/12** wrong-period/sign/restricted-cash/debt-basis variants, and four each of source-collateral, style, and stale non-target cached-display mutations. It executed **34** source/scenario counterfactual replays. Four copied seeds matched the original seeds byte-for-byte. A separate read-only evaluator reopened the frozen manifest, saved files, and 120 negative variants, reran the scorer, and spot-checked rendered views. One previously missing debt-note face source was extended from the original filing's dated inline-XBRL facts, then separately reviewed and signed. The audit also distinguishes true zero debt faces from unavailable source fields.

The source documents, issuer identities, accession IDs, case packages, workbooks, and answer-bearing audit stay evaluator-private with directory mode `0700` and file mode `0600`. The receipt exposes aggregate counts and SHA-256 commitments only. The locally generated detached review signature binds its key and audit bytes but does not certify an external human reviewer.

This is a TRAIN-only **offline** pilot. The positive workbooks were authored with the bundled spreadsheet runtime; no model performed the edits. A copied local seed is not a cloud reset. Excel for the web has not saved or downloaded these files, so none of the four cases is admitted to a researcher training run or any official final denominator. The remaining 22 cases in the planned 26-case transfer screen are not sourced by this receipt.
