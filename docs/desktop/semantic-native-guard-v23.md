# Desktop semantic native guard source candidate

This additive namespace replaces the action admission and passive readiness pixel/caret tests with actual owned X11 and GI/libatspi metadata. It retains the current episode's 90-action/720-second actor clock, 1200-second leases, original guest/content/profile attestation, saved-artifact scorer and distinct reset. Frozen v21/v22 code and old results remain unchanged.

The trusted guest probe reads active window, PID, UID, application class, AT-SPI active window, native state flags, desktop bounds and accessible-at-point results. It does not read cell/paragraph values, alter accessibility state or infer enabled/obscured targets from a static canvas. Missing APIs, ambiguous ownership/focus, unbounded trees and unknown dialogs fail before native/model dispatch.

Full unchanged observation and predispatch screenshots are retained alongside actual native envelopes. The shared guard decides ownership, window/view/modal/focus, target bounds/states, lease and nonce/TTL. Different pixels do not reject an action. Every rejection consumes its nonce; the same current episode loop records rejection separately and observes again. Intent precedes real GUI IO, which is recorded separately from acceptance. Targeted keyboard input verifies actual focus after pointer selection and before text/key IO.

The source keeps the existing seven readiness sample delays and five Calc Enter sample delays. It records every raw screenshot but checks native state/geometry rather than image equality. The old strict parser, caret retries and pixel settling proxy are not invoked in the new action path.

The common counterpart module supplies the same actor transport to teacher, reference controls, shared base and all four checkpoints. Its teacher invokes the current paid callback facade and existing dataset receipt translator. The source epoch manifest explicitly requires fresh qualification; neither old controls nor source registration grant activation.

## Read-only native probe

A root-reviewed fresh owned guest can receive the exact helper source in a trusted evaluator setup directory. After the normal guest/profile attestation and owned document open:

```bash
python3 /tmp/envloop-native-accessibility-v23.py \
  --filename ACTUAL_OWNED_FILE.xlsx --width 1280 --height 800
```

The output must report the exact helper SHA, observed native owner/window/application, actual state/geometry/hit metadata and zero mutations. `unavailable_or_unsafe` is an infrastructure result, never a model failure or safe fallback. The helper may need a new source version after inspecting the actual guest's AT-SPI availability or table traversal. No guessed native qualification is shipped.

## Offline source checks

```bash
PYTHONPATH=.:src python -m unittest \
  tests.test_native_desktop_accessibility_probe_v23 \
  tests.test_native_desktop_semantic_native_transport_v23 \
  tests.test_native_desktop_semantic_episode_engine_v23
```

These checks use synthetic native/provider IO. They cover actual probe traversal/state/hit logic, different-pixel acceptance, disabled/foreign/unknown rejection, keyboard focus ordering and the current episode's rejected-turn bookkeeping across five slots. They do not prove a live native epoch. Fresh raw control evidence, all seven actor paths, source registration and independent native IO/clock/reset replay remain required before activation.

The implementation follows the read-only [AT-SPI Accessible API](https://lazka.github.io/pgi-docs/Atspi-2.0/classes/Accessible.html) and the [GNOME PyAtspi source interface](https://gitlab.gnome.org/GNOME/pyatspi2). No focus, selection, scrolling or text mutation API is used by the probe.
