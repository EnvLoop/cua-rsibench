# Current Desktop teacher adapter

This source counterpart uses the same current native episode as shared base and the four selected student slots. It preserves the v21 files and pins. Its engine retains 90 actions, a 720-second actor clock, 1200-second E2B leases, current save/readiness checks, the independent saved-artifact scorer and a distinct fresh reset.

`current_episode_paid_id_v22.py` loads the exact pinned v21 engine in a separate namespace. Its only episode change is the deadline receipt's authentic paid-ID accessor. The common `PaidCalls` validates actual request, intent and dispatched bytes. Campaign sessions must supply their real paid-intent event. Shared-base sessions instead supply their normalized ledger envelope and exact worker-request reference. All five student slots must use this new wrapper in the witnessed v22 source registry; no old deadline or result is rewritten.

`current_teacher_worker_v22.py` invokes that exact `_episode` method. Its E2B facade uses the already reserved actor/reset callback. Its teacher facade calls the already paid teacher callback once, then reopens the actual session intent, request, response, budget entry and result SHA. It does not create a Tinker sampling call or a second teacher charge. A minimal normalized action projection is recorded separately from the actual teacher result SHA; actual response usage and paid IDs remain unchanged.

The worker admits only frozen TRAIN package identities after the actual study/source gate. A successful episode must pass the current independent saved-state and distinct-reset audit before translation into the existing teacher dataset receipt. Synthetic tests also run that existing receipt verifier. Wrong reset bytes and altered teacher result hashes are rejected.

`full_study_teacher_current_v22.py` loads the immutable older collector and changes only its reset predicate. A genuine typed teacher deadline may perform one distinct reset after the worker reopens the actual paid intent, actor budget/clock and owned actor-close proof. It inserts no finish action. The unfinished episode is retained and rejected as successful training data.

The current Desktop transport still has the existing physical-frame/caret guard. This teacher adapter shares that actual implementation. It does not claim that Desktop has completed the separate common semantic native-surface-guard migration.
