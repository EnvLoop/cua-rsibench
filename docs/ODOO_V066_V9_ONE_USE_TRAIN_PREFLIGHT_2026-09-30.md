# Odoo v9 one-use train route preflight

The [offline preflight receipt](evidence/odoo-v066-v9-one-use-offline-preflight-2026-09-30.json) verifies the current v9 source freeze against 30 files, the private nonce commitment, two distinct **train** RFQs, the prior v8 terminal record, an unused v9 run directory and an available train-worker lease at the time checked. Eighty-three targeted tests passed on the main checkout. No model, selection, hidden or official final task was dispatched. This is an offline review: the shared Docker context was in use by another workflow, so current Docker service state was deliberately **not** inspected. The lease observation is a point-in-time check, not a reservation.

After the root operator releases `colima-cua-scale`, perform these gates immediately before a single v9 run:

1. Confirm no Magento or other workflow still needs that Docker context. Read the context's running containers and the original train worker's Compose services without starting or stopping either. Require the train `db` and `web` services to be cold and no conflicting benchmark container to be active.
2. Re-run `tools.odoo_v066_train_attachment_calibration_v9._verify_freeze` against the public and private freezes. Confirm the original train worker lease is available and `attachment-route-train-pilot-20260929-07` still does not exist. If any check fails, preserve state and do not launch.
3. Launch **one** root-owned `tools.odoo_v066_train_attachment_calibration_v9 run --execute` using only the original train worker, the accepted train audit, and those exact freezes. This action uses the native Odoo GUI, with no model/provider call. Its first durable intent consumes the run ID even if startup or dispatch fails; never replay it.
4. On terminal success, independently reopen the saved source-viewer screenshot and PDF, every action/frame/route-token chain, positive and wrong-object SQL and complete filestore readback, cold reset and lease/service cleanup. Save the visual review privately, then run `tools.audit_odoo_v066_train_attachment_calibration_v9`. On failure, preserve the raw attempt and publish a field-limited terminal audit. Neither outcome admits a selection or official final task by itself.

The source-frozen candidate is the additive explicit router described in [the v9 ADR](ODOO_V066_TRAIN_ROUTE_ROUTER_V9_ADR_2026-09-29.md). A price-editor `double_click` without a strict route claim now produces a reason-coded **pre-intent** rejection; a claimed action carries one route token through the durable intent and dispatch. This addresses v8's silent fallback without widening the existing screenshot tolerance. The only current blocker to the one-use native check is a fresh shared-context handoff and service-cold verification.
