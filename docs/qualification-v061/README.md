# Real-software qualification addendum (v0.6.1)

[The two-page PDF](EnvLoop-Real-Software-Qualification-Addendum.pdf) and its [vector control diagram](figures/control-transitions.svg) supplement the [v0.6 qualification note](../qualification-v06/EnvLoop-Computer-Use-Qualification-Report.pdf). They report three development controls in real application surfaces: a SEC-grounded retail workbook in Excel for the web, one PPT-Eval selection task in PowerPoint for the web, and one WebArena-Verified Magento price task in a repaired disposable clone.

The full study remains at **0/24 researcher campaigns and 0/600 distinct official final task identities**. None of the three controls is a hidden final task or a student-model result. The scores in the diagram use different within-task verifiers and must not be averaged.

The addendum is generated by [`tools/build_v061_qualification_addendum.py`](../../tools/build_v061_qualification_addendum.py). It checks the public, field-limited [Excel](../evidence/sec-retail-working-capital-excel-web-controls-2026-09-24.json), [PowerPoint](../evidence/ppt-eval-office-web-gate-2026-09-24.json), and [Magento](../evidence/magento-variant-price-qualified-2026-09-24.json) receipts before rendering. Regenerate with a Python environment containing ReportLab:

```bash
python3 tools/build_v061_qualification_addendum.py
```

No account identifier, authenticated document URL, private workbook/deck, raw HAR, or evaluator-only answer is included in these files.
