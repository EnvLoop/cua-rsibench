# GitLab CE v0.6.6 train teacher episode worker

**Status: implemented interface and fake-provider validation only.** The [GitLab worker](../gitlab_world/teacher_episode_worker_v066.py) implements `run_episode(task, out_dir, sample_teacher, dispatch_e2b)` for the self-hosted original GitLab CE 18.5 web application. Its [source-bound offline receipt](evidence/gitlab-v066-teacher-worker-offline-2026-09-28.json) reports 18 passing no-Docker tests. No live teacher episode, model/provider call, selection or final task, official admission, or researcher campaign was run for this implementation. The existing 100-task deterministic GUI sweep and historical v0.6.4 actor are separate and unchanged.

The worker defaults to `enable_live=False`. Before opening the application, it requires a private six-cell ratification plus exact runtime, verifier and v0.6.6 adapter hashes. The requested task must match exactly one of the 20 private train tasks by ID, canonical package hash and visible instruction, with a distinct train project and a scoped non-admin train operator. The evaluator reads this binding privately; the actor receives only the task instruction and current original-GitLab screenshot with visible controls. A local-origin network guard blocks external browser requests. GitLab is self-hosted, so `requires_e2b=False` and the E2B callback is unused.

The real backend cold-resets the disposable GitLab overlayfs clone before the first observation, requires exact equality with the frozen PostgreSQL/Git baseline and an unsolved train oracle, and opens a fresh restricted browser context. It refuses to sample a page outside the assigned train project. Because the campaign's paid teacher callback is synchronous while Playwright is asynchronous, one dedicated event loop owns all browser objects. The callback's `current_frame_id` checks the physical screenshot; after the callback, the worker checks it again, validates the shared v0.6.6 action and dispatches it only through the proposed GUI actor. Each raw frame is stored mode 0600 before the callback. A stale frame aborts without replaying the paid call.

After a `finish` action, the browser reloads and the evaluator independently reads PostgreSQL rows and Git refs/blobs. The separate [train oracle](../gitlab_world/train_teacher_oracle_v066.py) checks the four original training workflows and rejects any unrelated persisted change. This new oracle leaves the source-bound final-candidate verifier unchanged. The backend then closes the browser, destroys the used clone through a second cold reset, compares the entire restored snapshot with the frozen baseline, and confirms the replacement container identity. Only a passing target/no-regression score and exact reset can produce an admitted private episode receipt. The upstream [teacher adapter](../src/cursibench/full_study_teacher_adapter_v1.py) independently reopens and hashes its frames, action trace, saved-state and reset artifacts before rendering Qwen training data.

Synthetic tests cover source and partition gates, all four train oracles with collateral-change negatives, fake paid-call ordering, physical frame drift, cross-project rejection, current-frame v0.6.6 dispatch, exact two-reset order, failed saved state and failed reset. They patch the environment boundary; they make zero Docker, E2B or external provider calls. A live train teacher episode still requires the completed six-cell ratification and an exclusively scheduled GitLab worker after development requalification. Actual provider costs and the 24 campaigns remain unmeasured.
