# v0.6 Tinker cost attribution

The v0.6 sampling server requires a `--campaign-id` and attaches it to Tinker session `user_metadata`. The trusted training controller must use the same campaign ID with the declared `cua-v06-training` purpose. This lets an auditor isolate one researcher×application lineage without publishing session IDs, user names, tokens, or credentials.

Tinker's [SDK billing API](https://tinker-docs.thinkingmachines.ai/tinker/api-reference/restclient/#get_billing_usage-starting_on-ending_before) returns organization-wide hourly events with training, sampling prefill, sampling output, checkpoint, and storage quantities. Requests use UTC hour boundaries and span at most 14 days. The endpoint requires billing-view access and can lag by a few hours; it does not return dollar amounts or an available credit balance. Export a response with `model_dump(mode="json")` into a private `0600` file under `work/scale-v06/private/`, never into a task sandbox or release archive.

[`reconcile_tinker_usage_v06.py`](../tools/reconcile_tinker_usage_v06.py) filters that private response to sessions whose metadata matches a single campaign and either the versioned sampling or training purpose. It applies rates from Tinker's [machine-readable `models.json`](https://tinker-docs.thinkingmachines.ai/tinker/models.json), pinned by SHA-256 in the reconciliation output. Cached and uncached prefill are distinct. Unknown-session, storage, checkpoint, different-model, credit, and promotional events are not silently converted to dollars. The output is a **published-rate token subtotal**, not an invoice, spend authorization, or all-in cost. The campaign controller must separately reserve and reconcile E2B, researcher/teacher inference, storage, licenses, and any provider credit balance before dispatch.

The 2026-09-24 `models.json` snapshot has SHA-256 `1521db910e08c3f2cc052e9c4f831cdc7b9fbca74ca2d4d2f07c1b544530dcef`. Its Qwen3.8-27B 64K public rates are $1.86 per million uncached prefill tokens, $0.372 cached prefill, $5.595 sampled tokens, and $4.103 training tokens. These rates must be snapshotted again at study freeze. The 256K variant is a different model ID and price row; do not mix its usage into the 64K ledger.
