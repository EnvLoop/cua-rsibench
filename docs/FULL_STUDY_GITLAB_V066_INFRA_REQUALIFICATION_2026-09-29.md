# GitLab CE v0.6.6: one infrastructure requalification after a terminal control

This dated amendment applies only to the current-profile GitLab evaluator control that became infrastructure-invalid when its disposable GitLab clone failed to become healthy. The original hash-chained journal, failed partial GUI attempt, supervisor result, failed batch receipt, and independent nine-control aggregate remain unchanged. It does not treat the infrastructure failure as a student-model miss, and it does not remove it from attrition reporting.

The older [pre-result recovery protocol](FULL_STUDY_GITLAB_PRE_RESULT_RECOVERY_2026-09-28.md) requires all 100 original first attempts before its general resolution and FIFO whole-family retirement. The source-frozen current-profile controller stopped at the first terminal failure after nine passing controls, so it cannot complete that denominator. This narrow amendment grants **one** same-identity fresh-clone requalification before any further current-profile dispatch. It does not authorize a third attempt, a changed identity, a task-specific controller fix, or a whole-family replacement.

## Source-bound branch and independent evidence

The freeze action in gitlab_world.v066_infra_requalification_v1 is a no-GUI operation in the original GitLab worktree. It verifies the terminal failed original journal, the supervisor's exact post-failure reset, both closed batch receipts, the source-frozen original plan, the saved nine-ID audit, and the failed partial-attempt bytes. It copies the exact original plan, the first 18 hash-chained passing journal events, and all nine passing attempt trees into a new mode-0700 private branch. No symlinks are permitted. The original failed event stays in the original journal and is bound by SHA-256 in the new private and public source freeze. The existing independent raw auditor reopens the copied nine-ID branch before freezing it.

The public freeze contains hashes and aggregate counts only. The source freeze binds this module, its tests, and this note. Any later source edit invalidates dispatch. The branch may diverge from the old journal only after an explicit digest-acknowledged retry command. Its first new action is the same original identity in a fresh disposable clone; the unchanged GUI controller must produce a complete positive/negative/repeated-positive trio, an unrelated-change rejection, and three consecutive independently checked cold resets. A separate child has the existing 7,200-second process-group watchdog. Failure writes a terminal branch result, attempts exact cleanup, and never replays automatically.

The initial no-GUI commands are:

    PYTHONPATH=src:. python -m gitlab_world.v066_infra_requalification_v1 freeze \
      --ratification-private /ABS/PATH/TO/v066-caret-amended-control-ratification-20260928.private.json

    PYTHONPATH=src:. python -m gitlab_world.v066_infra_requalification_v1 preflight \
      --ratification-private /ABS/PATH/TO/v066-caret-amended-control-ratification-20260928.private.json

After the public freeze is cherry-picked, pushed, and reviewed, the operator must pass the **exact SHA-256 of its public JSON file** and explicitly request execution:

    PYTHONPATH=src:. python -m gitlab_world.v066_infra_requalification_v1 run-requalification \
      --ratification-private /ABS/PATH/TO/v066-caret-amended-control-ratification-20260928.private.json \
      --public-freeze-sha256 THE_PUBLISHED_JSON_SHA256 --execute

Then use a separate process to reopen every branch GUI, PostgreSQL/Git, score, unrelated-change, and cold-reset record and publish a field-limited result:

    PYTHONPATH=src:. python -m gitlab_world.v066_infra_requalification_v1 audit \
      --ratification-private /ABS/PATH/TO/v066-caret-amended-control-ratification-20260928.private.json \
      --publish

The old batch controller remains permanently stopped on its terminal event. This amendment does **not** permit later-ID continuation from either the old controller or the branched journal. A separate source-frozen continuation controller, gated on a passing published requalification audit, is required before another ID can be dispatched. Until then, public and private receipts say "continuation_dispatch_authorized: false". Official final-task admissions, researcher campaigns, and student-model outcomes remain zero.
