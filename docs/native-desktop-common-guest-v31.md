# Common native Desktop guest and episode

This additive source implements the same owned guest path for teacher, control, shared base, Astra, Sol 5.6, Sol 6 and Luna 6. It installs the official pinned V25 AT-SPI typelib before the existing original-source/profile preparation, runs the new native reader only in a child with the additional GI search path, and combines the real base content hash with the actual installed typelib and bootstrap receipt. The per-guest manifest and supplemental epoch are independently reopened for both actor and distinct reset guests. All old modules and evidence are preserved.

The V31 point reader closes the V30 ambiguity: a missing root hit cannot become an enabled window target. A virtual or large container miss cannot become a table target. A terminal hit requires an actual preceding parent hit, current native ownership/geometry/state, and a native zero-child leaf. A disabled or insensitive ancestor prevents an enabled descendant. Deferred focus remains unknown; selection is never used as a substitute for a native `FOCUSED` state.

`CommonGuestFactory` is a concrete provider factory. Its formal `create_guest` method checks fresh independent native qualification before calling a provider, requires active-zero, writes an exclusive create intent, journals the returned raw handle before wrapping or preparation, and uses one bounded cleanup invocation on constructor failure. Source-only construction grants no paid authorization. `wrap_owned_guest` permits a root-reviewed development probe to use an already-owned guest; it neither creates another guest nor grants native/task credit. The bootstrap's exact source and asset prerequisites and its fresh-profile check remain unchanged.

`DesktopCommonNativeWorker` reuses the current episode, actual paid identity, saved-artifact scorer and distinct reset through the new transport. Its five student slots retain the same 90 actions, 720-second actor clock and 1200-second lease. `DesktopCommonNativeTeacherWorker` uses the same current episode and the authentic already-paid teacher callback without a second sampler charge. `CommonNativeControlDriver` uses the same dispatch body and native policy. The wrapper independently checks both actual base and supplemental content after the existing saved-score/reset audit. Current selection/final study gates are inherited; the new native qualification gate must also pass before their paid calls. Constructors and source registration remain unqualified.

Source and local preparation commands:

```bash
PYTHONPATH=.:src python -m native_desktop_factory.common_native_guest_v31 source
PYTHONPATH=.:src python -m native_desktop_factory.common_native_guest_v31 prepare-host --out work/native-common-v31-host.private
PYTHONPATH=.:src python -m unittest discover -s tests -p 'test_native_desktop_visible_surface_probe_v31.py' -v
PYTHONPATH=.:src python -m unittest discover -s tests -p 'test_native_desktop_common_native_guest_v31.py' -v
```

A prospective root-owned development probe can construct a factory from the exact saved manifest, wrap the separately journaled raw guest at the `gui/task/actor` hierarchy, and call `prepare` with the actual public TRAIN package and current guest/profile references. Preparation performs the reviewed offline bootstrap first and then one prepared native read. That is a separate concrete execution scope; these commands do not authorize creating or running a guest.

Formal activation still requires independent reopening of fresh native evidence for all seven actor paths, all three native app kinds, 120 current control trios, actual native IO and actor clocks, and each distinct actor/reset base plus supplemental content. The existing Writer/Impress ownership candidates remain disabled until their actual identities are observed and source-bound. No historical row is promoted. The reader is not qualified by the available Calc namespace, partial branch, timeout or offline tests.

The native probe command is bounded to 45 seconds with a 55-second request, and bootstrap commands retain the reviewed 20/30 bounds and 15-second namespace child. The actor budget and guest lease are not extended. Requested points retain the model's exact coordinates; fresh native disabled-child or ownership evidence rejects the action without retargeting. Raw full images and native envelopes remain separate from scoring.

The V31 diagnostic retains first failed native API stage and stores full GI errors exclusively in a mode-0600 fixed guest error file. Public output contains its hash and stage. The common transport privately reopens that file and checks its declared SHA and byte count before persisting a private error receipt; raw messages never enter model observations.

The separate V32 stderr correction classifies only AT-SPI Accessible getter deprecation blocks with an exact trusted helper path, supported getter name, frozen source hash and exact source continuation line. The saved actual V27 `get_collection_iface` warning is the fixture. The official GNOME API recommends the existing `get_component_iface` interface method, so that supported getter uses the same narrowly bound warning form if GI emits it; this is not a claim that its warning was observed. Raw stderr stays unchanged in the private command receipt. Unknown stderr, a changed source line/hash, a failed exit status, or failed typed native metadata still rejects the probe. Warning classification never implies native success or qualification.
