02 / REAL APPLICATION

原生界面，真实状态

实际运行截图。应用版本 1.2.54；动作由模型产生。

模型能做什么

读取当前可见 DOM 文字和控件，点击、输入、选择、有限按键与返回。模型没有 SQL、文件、shell 或应用 API 工具。

数据哪些是真实的

issue 标题、状态、标签、时间戳、评论数和来源 URL 来自公开 GitHub。负责人、工作流政策与排期预算明确标为构造条件。

如何验证

主控读取初始和最终 SQLite 状态，检查目标字段及其他任务、描述、评论、项目的完整性。截图和模型自报不是评分依据。

已知限制

当前是 DOM 辅助浏览器操作，不是纯像素定位或完整 Windows/macOS 桌面；单次小样本不能推出模型总体排名。
