# Read-only Qwen runtime gate before paid campaign work

The [pre-dispatch interface](../src/cursibench/full_study_qwen_runtime_gate_v1.py) is wired into both paid-call boundaries: the campaign controller for train-only LoRA SFT and candidate selection sampling, and the one-time shared-base selection controller. It reopens the public clean-runtime/toy receipt, frozen runtime specification, wheel lock, original toy runner and read-only attester source hashes, and all four private toy files. It checks the private checkpoint binding and provider-reported base model without exposing the checkpoint URI. It then launches the dedicated root-checkout venv's [offline verifier](../tools/verify_qwen38_training_runtime_v1.py) as a subprocess with provider credentials removed and Hugging Face offline mode forced.

The function requires the venv at `work/qwen38-training-runtime/.venv`, the pinned cookbook checkout at `work/tinker-cookbook-pinned`, and the private second-toy evidence directory at `work/full-study/tinker-qwen38-vision-paid-transformers554-20260928` **in the same durable root checkout**. Its four evidence files must retain their original bytes and mode 0600. The active paid-call process must itself use that exact dedicated venv, with user site disabled, no external `PYTHONPATH` overlay, and all six critical provider/renderer packages imported from the dedicated venv. The [runtime build procedure](FULL_STUDY_QWEN38_TRAINING_RUNTIME.md) documents the environment. Run the campaign process with the root checkout's `work/qwen38-training-runtime/.venv/bin/python`, using only absolute root and `src` paths if `PYTHONPATH` is set.

The read-only audit returns the study-plan, runtime-spec and public toy receipt hashes, reports zero provider calls, and explicitly sets `dispatch_authorized` to `false`. Immediately before each Tinker dollar reservation, both controllers require that audit and check the active interpreter and package origins. The campaign journal and shared-base paid-request envelope bind the runtime-spec, public-toy and gate-source hashes; refusal leaves no Tinker reservation, request file or provider call. The six-cell freeze, source/task partition, budget and replay gates remain separate. Synthetic tests cover SFT, candidate-selection sampling and shared-base sampling refusal before provider dispatch. This code has made no campaign call and supplies no official task admission or model result.

The [dated offline receipt](evidence/qwen38-dispatch-gate-offline-2026-09-28.md) binds the current sources and records 44 fake-provider tests under a Python socket block. It supersedes the source hashes in earlier shared-base fake-only receipts without altering their historical files.
