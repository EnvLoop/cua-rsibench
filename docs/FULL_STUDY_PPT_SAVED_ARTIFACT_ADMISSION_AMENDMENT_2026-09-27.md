# PowerPoint saved-artifact admission boundary — 2026-09-27

**Pre-result amendment, before any model or official final admission.** The PowerPoint evaluator originally required both an editor reload and a newly opened editor session to confirm every target after an isolated GUI control. The latter fresh-session thumbnail click proved intermittently unavailable in this personal Microsoft account even when the independently downloaded PPTX contained the fully restored target drafts and preserved chart/workbook state. Two successive attempts on one v10 candidate hit that GUI-control failure; its entire four-task source family remains excluded under the previously published [one-retry rule](FULL_STUDY_PPT_PRE_ADMISSION_RETRY_RULE_2026-09-27.md). This amendment does **not** retroactively promote that candidate.

The authoritative per-ID saved-state evidence is the **downloaded PPTX**, independently parsed and scored against a source-bound, evaluator-frozen application-native baseline. The evaluator must still perform visible GUI edits in PowerPoint for the web, observe each required target in the same editor, reload that editor, and download the file from OneDrive. A second, read-only download of the same named cloud file is required after closing the editor. Both bytes and verification results are retained; an early stale copy is labeled infrastructure-invalid, and only the later independently checked file can satisfy the control. If that later copy is still stale or fails any target or preservation check, the control is unqualified. A separately uploaded **fresh-copy reset** must prove the original draft state and no collateral change. Opening a third editor session is now diagnostic only and is not a prerequisite for admission or scoring.

This change removes a flaky observation step, not a saved-state check. It does not relax the visible GUI action requirement, the four-target positive/partial/collateral checks, chart/workbook/no-regression preservation, task/source isolation, the cap on pre-admission infrastructure retries, or the six-cell campaign freeze. The retained v10 failure stays failed and the fifth source-family replacement is pending. PowerPoint official final admissions, hidden-model attempts and researcher campaigns remain **zero**.
