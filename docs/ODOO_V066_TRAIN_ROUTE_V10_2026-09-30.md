# Odoo train route v10: price editor owning row

The [v9 terminal audit](evidence/odoo-v066-train-attachment-route-v9-terminal-2026-09-30.md) independently verified three `sku_row_not_unique` price-route nonclaims. Each observation had one visible price input; observed and rejected-current PNGs were byte-identical. V9's explicit route protocol correctly stopped all three `double_click` attempts before an action intent, with no generic fallback. The saved evidence did not identify the extra matching `tr`, so v9 is terminal and must not be replayed.

V10 changes only the train price editor lookup. It begins with **exactly one visible `td[name="price_unit"] input`**, finds that editor's nearest owning `tr`, and requires its direct `td[name="product_id"]` to contain the frozen SKU. It no longer enumerates every ancestor or nested `tr` whose combined text happens to include the SKU. The same DOM read returns a reason code and strict target identity, avoiding disagreement between separate diagnostic and actor lookups. Exact positive and wrong-object train RFQ routes/IDs, original price, editor focus and writability, modal absence, target hit, task/frame/URL token, two final physical frames at parse and dispatch, and independent saved-state/reset scoring remain unchanged. Multiple visible editors, wrong product cells, changed rows, modals or stale frames still fail closed.

Synthetic Chromium reproduced v9's failure on a nested-table fixture: the old global row search returned `sku_row_not_unique`, while the new editor-owning-row lookup claimed the single correct input. Adversarial DOM tests reject duplicate editors, wrong product-cell SKU, modal and wrong route. Positive and wrong-object integration tests verify the unchanged route-token-in-intent boundary and pre-intent rejection for an unclaimed editor. **Eighty-seven** targeted tests passed. The [public v10 source freeze](evidence/odoo-v066-attachment-train-source-freeze-v10-2026-09-30.json) binds a fresh private nonce and 31 source files; the new run directory is `attachment-route-train-pilot-20260930-08`.

V10 is source-only. No Docker service, GUI action, model call, selection/hidden read or official final evaluation was dispatched for this version. The original Odoo DOM was not retained in v9, so a root-owned one-use train-only native attempt and independent visual, positive/wrong-object SQL, full filestore, reset and lease audit are still required before claiming a train control. This source freeze does not admit an official final task.
