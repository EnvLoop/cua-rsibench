# Magento v2 one-case modal-stop supplement (prospective)

**Status: proposed before any model result, cleanup, or retry.** The frozen
v2 source and its first 14 completed evaluator controls remain unchanged.
The fifteenth case stopped in `positive-neutral`, before its candidate GUI
edit, when a release-notification loading mask and confirmation modal
intercepted the Content-menu click. The [dated read-only audit](evidence/magento-v2-stop-after-14-controls-2026-09-28.md)
recorded two exact monitored-state readbacks, the same two disposable
application/search containers, and zero changed derived-price rows. Its
receipt authorized neither cleanup nor retry. Later read-only UI observations
included a Content-menu click with zero business edits; the old state audit
cannot substitute for a fresh pre-cleanup readback.

The original v2 classifier is narrower than the general phrase “CMS-menu
timeout.” It requires an `item-edit` visibility error. The stopped stderr
instead records release-mask/modal pointer interception. Calling this an
already covered v2 retry would be false. This supplement makes the difference
public: if adopted, it adds exactly one **new pre-result infrastructure
classification** for case ordinal 15, with the original v2 CMS-menu class
used only as a compatibility value inside the unchanged v2 reconciliation
and final-audit functions. The sidecar freeze and final report must expose
both the supplemental classification and that compatibility mapping.

The source-bound wrapper may classify only the retained original journal
prefix, original stderr/process bytes, same task/package, `positive-neutral`
nonzero exit, no candidate GUI intent or saved result, and the exact material
state on a fresh two-read audit. The private freeze also binds both later
UI-only observation receipts and their screenshots, including the recorded
Content-menu click and zero business edits. It freezes the wrapper and independent
final-auditor source bytes, frozen v2 source hashes, original 100-task roster,
the 14 completed receipts, and the stopped-attempt audit before cleanup.
A private cleanup intent is written before any container action. The original
v2 reconciler still performs exact-pair stop/remove with its own append-only
intents and receipts. Only after both containers are absent and one bounded
`attempt_reconciled` event exists may the unchanged v2 runner perform a
fresh whole-case attempt on the **same** fifteenth task. The failed attempt,
all old receipts, and its cost remain in the denominator. A second retry,
different task ID, altered source, changed live state, or unclassified later
failure stops the campaign.

The independent final auditor must re-open the supplemental freeze, source
hashes, stopped journal prefix, sidecar cleanup intent/receipt, original v2
reconciliation chain, all 100 saved-state positive/near-miss/reset controls,
and the original first 14 receipt digests. Its public result must say
“v2 with one dated modal-stop supplement,” report the invalid attempt and
one retry, and keep model calls and official final admissions at zero.
If the current pair fails exact fresh-state checks or this source-bound
lineage cannot be reconstructed, the recovery path is a clean v3 100-case
run with the stopped v2 evidence retained and excluded from v3's denominator.

The guarded operator sequence is `prepare`, `audit-live`, explicit
`cleanup --execute-cleanup`, explicit `resume --execute-resume`, then the
separate read-only final auditor. Each command uses the original private
plan, original source checkout, parent and v2 freezes, and the same run
directory. `prepare` only writes a new private source freeze. `audit-live`
rechecks the exact current pair and writes the v2 reconciliation audit but
does not clean it up. Cleanup and resume are distinct irreversible stages;
an absent, changed, or partial receipt stops the next stage. The source
receipt is public before either stage and has `cleanup_authorized: false` and
`retry_authorized: false` until the explicit operator actions succeed. No
historical 35-case development control or current 14-case partial receipt
becomes an official final task by this amendment.
