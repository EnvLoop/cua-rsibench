the actual observation. If the candidate is outside the viewport, it selects a
normal targeted scroll at the current viewport center. The unchanged V13 guard
checks workspace, account, current native hit, modal, lease, nonce and deadline
before the actual mouse move/wheel call. The normal durable journal records the
scroll as an applied action only after the real driver returns. The reference
then takes a new observation and resolves the original candidate again before
clicking, filling or double-clicking it.

Each scroll uses one fresh nonce and one of the original 90 actions, within the
same 720-second actor clock. There are at most eight scrolls per candidate.
Missing, duplicate, hidden or oversized candidates stop before intent. A
rejected or uncertain scroll stops without a click, resubmission or action
replay. The reference does not call locator scrolling, clamp coordinates,
expand the viewport, reduce the roster, filter away another task or branch on
an answer. Existing optional-facet waits remain ordinary guarded wait actions.
