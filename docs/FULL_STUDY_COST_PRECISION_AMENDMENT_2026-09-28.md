# Full-study actual-cost precision amendment (2026-09-28)

This is a pre-result accounting amendment. It changes neither the frozen six-cell task design nor any declared budget limit. Actual paid-dispatch amounts can be as small as a billionth of a US dollar, while the original result and publication validators accepted only six decimal places. Truncating or rounding those amounts before an exact reconciliation could hide a cap overrun or make an invoice appear to match when it does not.

From this revision onward, actual campaign usage components, campaign all-in totals, provider invoice totals, per-round trajectory costs, and final task/execution costs must be finite, nonnegative **decimal strings with at most nine fractional digits**. The dollar ledger already uses that precision. These values are parsed as `Decimal` and summed and compared without float conversion or silent quantization. Frozen manifest and budget **declarations** continue to use their existing six-decimal schema. Every actual nine-decimal amount is compared exactly with those declared caps; `500.000000001` exceeds a `500` cap.

`provider_invoice_usd: null` means a provider invoice total is unavailable; it is not numeric zero. A campaign marked `published_rate_nominal` must keep that field null. A campaign marked `provider_billed` must provide an exact, non-null provider invoice total equal to its all-in subtotal. A final execution marked `provider_billed` must be backed by each task's private provider-usage receipt and invoice hash; the independent cost review still checks the actual provider documents. A result is never called invoice-complete merely because a published-rate estimate happens to equal a bill.

The result audit, publication usage aggregation, trajectory audit, and final dispatch controller now use the same nine-decimal actual-cost parser. Synthetic tests cover seven- and nine-decimal microcharges, exact campaign/final subtotals, a one-billionth-dollar overrun, and invoice-null handling. The tests make no provider calls and are not benchmark cost observations. This amendment must be included with the protocol and code before any official paid final evaluation and its revision recorded in the immutable final-dispatch witness commit.
