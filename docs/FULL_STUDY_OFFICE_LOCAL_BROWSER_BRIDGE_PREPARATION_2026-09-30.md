It should accept only the existing normalized current-frame GUI action object and a trusted private document binding. It should hold one serialized account lease, use one bound document tab, and receive no account credentials, Graph scope, source CSV, task gold, or evaluator paths.

The evaluator should open the neutral actor document, inspect source bindings, and complete upload, export, reset, and cleanup outside the model loop. The model should receive only the current document view, the visible task instruction, and prior action result. The bridge should return only bounded action results and hashes; scoring should consume evaluator-held saved artifacts through the existing independent scorer.

Before any model call, the dispatcher must verify the exact document identity and safe document surface. Before every action it must recheck document identity, screenshot frame, lease, and focused editor. A navigation mismatch must stop the episode before another screenshot can reach the model. Native app control, file pickers, browser address bars, account menus, application launchers, sharing, File navigation, unrelated tabs, cookie/session access, URL actions, selectors, and application content APIs must be unavailable to the actor.

Coordinate clicks need a reviewed safe-region map; text insertion and selection need a verified document editor focus. Keyboard chords must be mapped to the local platform through an explicit small allowlist, excluding browser/OS navigation. Double-click must open exactly one document editor. The collection exposed an extra native session after an initial OneDrive double-click and a recoverable deletion failure while that session remained open; the bridge must reject parallel same-document sessions rather than treating a folder item count as a session count.

Those checks would prepare a dispatcher, not prove live isolation. A later bounded native model episode must still demonstrate actual action execution, save readback, exact independent downloads, fresh reset, cleanup, and unchanged-scoring acceptance before any model-control claim.
